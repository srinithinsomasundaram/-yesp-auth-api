# Yesp Entitlements

**Domain: WHAT CAN YOU USE?**

Gates product and feature access based on what an organization has purchased.

## Planned responsibilities
- Product access grants (is SheetPro enabled for org X?)
- Feature flags per plan tier
- Seat / usage limit enforcement
- Grace periods and trial access

## Key principle
Entitlements sits between Billing ("paid for SheetPro Pro") and
the Application ("user opened the Reports tab").
It answers: is this feature available to this org at this plan level?
