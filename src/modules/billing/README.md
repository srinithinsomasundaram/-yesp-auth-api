# Yesp Billing

**Domain: WHAT DID YOU BUY?**

Manages commercial transactions for the Yesp ecosystem.

## Planned responsibilities
- Subscriptions (plan, billing cycle, renewal dates)
- Invoices and payment history
- Payment methods
- License seat counts per organization
- Upgrade / downgrade flows

## Key principle
Billing knows what the organization has **purchased**.
Entitlements decides what that purchase **enables**.
